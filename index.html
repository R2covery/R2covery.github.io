VSCode的Markdown插入本地图片，并使其在本地和hexo博客上都正常显示

发表于 2025-02-16 更新于 2025-02-17 分类于 config 本文字数： 499 阅读时长 ≈ 1 分钟

解决方法

参考hexo博客显示markdown路径的图片 - 知乎的解答：

  1. 先下载hexo-image-link插件： npm install hexo-image-link --save
  2. 在hexo博客根目录下的 _config.yml中设置 post_asset_folder: true
  3. 这时候使用 npx hexo new "post"，可以看到在 source/_posts下面会创建一个 post.md及其同名文件夹，将需要引用的图片放进同名文件夹（即 {% asset_img "图片名.png" "图片描述" %}）
  4. 正常执行 npx hexo clean && npx hexo g ，就可以看到自动转换成asset方法的引用
